🔗 DATA FLOW: SENSOR → CALCULATION → UI
═══════════════════════════════════════════════════════════════════════════════════════════════════

1. PHYSICAL SENSOR
   └─ Veeder-Root ATG (RS-232/TCP)

2. FAMS_ATG_COMMUNICATIONS (IoT Layer)
   ├─ Parse frame: <SOH>I20100...DEPTH=1425mm<ETX>{CHECKSUM}
   ├─ Validate checksum (XOR)
   ├─ Extract tank data
   └─ Output: AtgInventoryFrame (DeviceId, TankNumber, VolumeLiters, etc.)

3. FAMS_TANKS_BUSINESS (Domain Layer)
   ├─ Input: Depth (1425mm), Temperature (22.5°C)
   ├─ Calculate: Volume using geometric formula
   │  └─ volume = 14250.5 L
   ├─ Calculate: Capacity %
   │  └─ capacity% = (14250.5 / 19000) × 100 = 75%
   ├─ Calculate: Status
   │  └─ status = "Healthy" (between 15-85%)
   ├─ Output: TankTelemetrySnapshot
   │  ├─ CurrentVolumeLiters: 14250.5
   │  ├─ CapacityPercentage: 75.0
   │  ├─ Status: "Healthy"
   │  └─ CommunicationStatus: "Healthy"
   └─ Persist to database

4. MASTER SKILL Part 6 (API Layer)
   ├─ Service: POST /api/tanks/{id}/telemetry
   └─ Response: API Envelope with TelemetrySnapshot

5. MASTER SKILL Part 4 (State Layer)
   ├─ Pinia: useTankStore()
   └─ Update: tanks[index] = snapshot

6. FAMS_VUE_CORE (Frontend Layer)
   ├─ Component: TankCard.vue
   ├─ Display:
   │  ├─ Volume: "14250.5 Liters"
   │  ├─ Capacity Bar: 75% (emerald/green)
   │  └─ Status Badge: "Healthy"
   └─ Result: User sees real-time dashboard
