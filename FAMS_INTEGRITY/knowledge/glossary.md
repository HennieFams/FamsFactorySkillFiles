# Glossary

- **ATG** — Automatic Tank Gauge
- **IOT device** — inline sensor reporting dispensing volume directly
- **Android log** — handheld device log, includes raw totalizer readings
- **UnqTrID** — reconciled unique transaction ID (target of backfill)
- **TransactionID** — legacy/source transaction identifier
- **Recnumber** — record provenance flag (e.g. manualAdd, importFams)
- **Totalizer / TotalizerEnd** — meter readings; `ABS(TotalizerEnd - Totalizer)` = volume dispensed per the physical meter
- **InformationRec** — JSON blob attached to a UsageDispensing row
