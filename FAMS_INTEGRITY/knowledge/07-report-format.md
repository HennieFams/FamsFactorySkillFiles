# Report Format (pointer)

See `reports/` for the actual templates, one per audience:

- `reports/executive-summary.md` — short, non-technical
- `reports/anomaly-report.md` — itemized findings
- `reports/integrity-report.md` — full account review
- `reports/management-report.md` — operational/actionable
- `reports/technical-report.md` — full detail incl. SQL used

Pick the template matching who's going to read it; don't default to the
most technical one for an executive audience.
